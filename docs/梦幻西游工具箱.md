
## 一、产品概述

### 1.1 产品定位
一款运行于 ZTools 平台上的轻量级个人财务记账插件，专门为《梦幻西游》多开玩家设计。覆盖**游戏内梦幻币收支**、**RMB充值消费**、**藏宝阁交易**三大财务场景，并提供**账号在线状态管理**与**多维度统计分析**，帮助玩家一站式看清"赚了多少、花了多少、哪个号最值"。

### 1.2 目标用户
- 多开玩家（拥有 2 个以上游戏账号），需要管理多账号的收支与在线状态。
- 有记账习惯，希望量化每日游戏收益、RMB 投入产出比的玩家。
- 频繁使用藏宝阁买卖物品/角色，需要跟踪手续费和回款周期的玩家。
- 需要简单分析各账号产出效率、优化多开策略的玩家。

### 1.3 核心价值
- **一键上下线**：打开插件即选号上线，全部下线一键搞定，自动计时，彻底告别"忘了哪个号在线"。
- **极速记录**：快捷键呼出浮窗、模板一键记录、截图 OCR 识别，单次记账 3 秒内完成。
- **全场景覆盖**：游戏内梦幻币流水 + 点卡充值 + 藏宝阁交易 + RMB 消费，一个插件管全部。
- **智能换算**：数量 × 单价自动算出梦幻币价值，藏宝阁自动扣除手续费显示到手金额。
- **一目了然的看板**：梦幻币 + RMB 双维度汇总，图表直观展示收入、支出、净收益。

## 二、功能模块清单

### 模块一：账号配置与在线状态管理

| 功能点               | 功能描述                     | 交互说明                                                                                                           |
| :---------------- | :----------------------- | :------------------------------------------------------------------------------------------------------------- |
| **1.1 账号管理**      | 管理多个游戏账号，含名称、服务器、备注。     | 设置页提供「添加/编辑/删除」操作。必填：账号名称；选填：服务器、备注。账号列表作为全局下拉选项的数据源。                                                          |
| **1.2 物品字典**      | 管理常用物品，支持分类标签。           | 设置页提供「管理物品」入口，每个物品可设置：名称、分类（道具/装备/消耗品/梦幻币/宠装/其他）、参考单价（选填，用于快速填充）。记录时支持从字典快速选择，也支持临时输入。                         |
| **1.3 收支分类体系**    | 预置三大记账大类，每类下设子类型。        | **三大类**：① 游戏收支（子类：日常/副本/摆摊/打造/炼妖/其他）② 点卡充值（子类：散点/月卡/年卡/锦衣/祥瑞/传音/其他）③ 藏宝阁交易（子类：出售/购买）。不同大类走不同的记录表单。             |
| **1.4 启动上线面板**    | 打开插件时，若无账号在线，自动弹出上线选择面板。 | 面板列出所有账号（默认全选），提供三个快捷按钮：<br>•「沿用上次」一键恢复上次上线的账号组合<br>•「全部上线」选中全部<br>•「暂不上线」跳过，进入离线模式<br>勾选后点击「确认上线」，选中账号立即开始计时。 |
| **1.5 常驻在线状态栏**   | 插件主界面顶部始终显示各账号在线状态。      | 横向排列所有账号标签，每个显示：🟢/⚫ 指示灯 + 账号名 + 已在线时长（如"2h34m"）。点击指示灯可快速切换上线/下线。右侧提供「全部下线」按钮，点击后弹窗汇总本次各账号在线时长，确认后全部下线。        |
| **1.6 智能关联上下线**   | 记录收支时，自动关联账号在线状态。        | 当用户对某个离线账号记录收支时，弹出提示"该账号当前离线，是否同时设为在线？"，确认后自动上线并开始计时。全部下线时，弹出本次会话摘要。                                           |
| **1.7 上线历史与会话记录** | 每次上线→下线形成一条会话记录，统计在线时长。  | 每个账号可查看「上线历史」：日期、上线时间、下线时间、持续时长。统计看板中可查看每日/每周总在线时长趋势。                                                          |

| :------------------- | :------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| **2.2 快捷模板记录**       | 为高频操作创建一键模板，点击即记录。                                | 设置页预设模板：账号 + 物品 + 收支类型 + 子类型。**数量和单价设为选填**：填了则点击直接记录；不填则点击后弹出迷你输入框补填数量/单价再确认。                                                                                                                                                                                         |

### 模块四：藏宝阁交易管理

| 功能点 | 功能描述 | 交互说明 |
| :--- | :--- | :--- |
| **4.1 出售上架记录** | 记录在藏宝阁上架出售的物品/角色。 | 表单字段：账号、物品名称、上架价格、上架时间。状态自动设为「上架中」。 |
| **4.2 出售成交记录** | 物品卖出后，补充成交信息，自动计算手续费。 | 在「在售物品列表」中找到该物品，点击「已售出」→ 弹窗输入：成交价格、成交时间 → 系统自动计算：**手续费 = 成交价 × 费率（默认 5%）**，**到手金额 = 成交价 − 手续费**，**预计到账日 = 成交日 + 3 天**（可配置）。 |
| **4.3 下架/过期处理** | 物品未卖出下架或过期自动下架。 | 手动点击「已下架」并选择原因（手动下架/到期下架）。过期物品系统可做提醒标记（上架超过 7 天标黄，超过 14 天标红）。 |
| **4.4 购买记录** | 记录在藏宝阁购买的物品/角色。 | 表单字段：账号、物品名称、购买价格、购买时间、备注。 |
| **4.5 在售物品看板** | 集中展示所有「上架中」的物品。 | 卡片列表形式：物品名称、上架价格、已上架天数、所属账号。按上架时间排序。支持一键「已售出」「已下架」操作。 |
| **4.6 手续费费率配置** | 支持自定义藏宝阁手续费费率。 | 设置页提供费率输入（默认 5%），所有出售记录的手续费按此费率计算。到账延迟天数也可配置（默认 3 天）。 |
| **4.7 到账提醒** | 物品售出后，预计到账日到期时提醒。 | 在到账日前一天或当天，插件内显示提醒标记："XX 物品今日/明日到账 XX元"。 |

## 三、非功能性需求

| 类别 | 需求描述 |
| :--- | :--- |
| **性能** | 插件启动、记录操作、看板加载响应时间在 1 秒以内。OCR 识别在 2 秒内出结果。 |
| **数据安全** | 所有数据仅存本地，不上传云端。提供手动 JSON 备份及 CSV 导出功能。 |
| **UI/UX** | 深色主题，与游戏客户端视觉协调。按钮大而清晰，适合游戏间隙快速操作。在线状态指示灯醒目直观。 |
| **平台兼容** | 作为 ZTools 插件，兼容 Windows 和 macOS。全局快捷键需避让游戏热键（默认 `Ctrl+Shift+R`，可自定义）。 |
| **扩展性** | 数据模型预留扩展字段。支持自定义收支子类型、自定义物品分类、自定义藏宝阁费率。 |
