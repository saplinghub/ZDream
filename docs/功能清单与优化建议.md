# 梦金囊 · 功能清单与优化建议

> 最后更新：2026-07-29  
> 版本：v0.1.4

---

## 一、看板（Dashboard）

### 已实现

| 功能 | 说明 |
|------|------|
| 时间范围切换 | 今日 / 本周 / 本月 / 近30天，四个按钮切换 |
| 梦幻币净收益卡片 | 收入 + 消耗 + 净收益，≥1万自动用"万"显示 |
| RMB 净收支卡片 | 入账 + 支出 + 净收支，超预算时卡片变红 |
| 在线总时长卡片 | 当前在线总时长 + 在线账号数 / 总账号数 |
| 记录条数卡片 | 范围内记录总数，按游戏/点卡/藏宝阁分类 |
| 账号对比 | 柱状图模式和表格模式可切换，按账号展示梦幻币收入/消耗/净收益/RMB |
| 收支趋势图 | 折线图：绿实线收入 + 红虚线消耗，支持梦幻币/RMB 切换；按时间范围自动分桶（今日按小时、周/月按天、30天按3天一桶） |
| 到账提醒 | 藏宝阁物品即将到账时顶栏红色提示条 |
| 预算超限提醒 | 本月 RMB 超预算时顶栏显示 |
| 最近流水 | 最新 8 条记录摘要，点击可跳转记账页 |

### 待优化

- 趋势图暂无数据时有空状态占位，但缺少引导文案（如"记录一笔收支即可看到趋势"）
- 账号对比柱状图在无数据时显示空白列，可优化空状态

## 二、动态（Live）

### 已实现

| 功能 | 说明 |
|------|------|
| 动态事件流 | 上线/下线/记账/藏宝阁操作自动生成事件，实时推送到动态页 |
| 事件类型区分 | 收入（绿色）、消耗（红色）、系统（灰色）、藏宝阁（蓝色）四种颜色标签 |
| 独立悬浮窗 | Tauri 桌面端可弹出独立窗口（置顶）；浏览器端降级为页内浮层 |
| 收成小图标 | 悬浮窗可收成停靠图标（LiveDock），点击恢复 |
| 导航栏动态入口 | 带事件数角标徽章 |

### 待优化

- 动态事件不支持筛选，时间久了会很多
- 不支持清空全部动态

## 三、记账（Ledger）

### 已实现

| 功能 | 说明 |
|------|------|
| **游戏收支** | 选择账号 → 物品 → 数量×单价 → 收入/消耗 → 子类型（日常/副本/摆摊/打造/炼妖/其他）→ 备注 |
| **点卡购买** | 选择账号 → 卡类型（月卡/年卡/点卡）→ 金额 → 点数 → 备注 |
| **RMB 消费** | 选择账号 → 消费类型（锦衣/祥瑞/打造/炼妖/其他）→ 金额 |
| **快捷模板** | 预设常用记账模板，一键填入表单 |
| **快捷浮窗** | Ctrl+Shift+R 弹出浮窗，快速记录游戏收支（支持数量×单价+收/支+子类型） |
| **历史记录** | 三个 tab：游戏收支历史 / 点卡+RMB历史 / 统一流水（全部类型混合） |
| 流水筛选 | 按账号/大类/关键词筛选 |
| 记录复制 | 游戏收支支持复制已有记录回填表单 |
| **记录编辑** | 点击"编辑"弹出表单，自动识别记录类型（游戏/点卡/消费/藏宝阁）渲染对应字段，保存后重算所有派生值 |
| 记录删除 | 三条面板均支持删除，确认即删 |

### 待优化

- 记账后自动上线逻辑已有（`ensureOnlineFor`），但只在 game/card/spend 三种类型触发，cbg 未触发
- 快捷模板管理（编辑/删除模板）尚未实现
- 统一流水列表的筛选器略简陋，没有日期范围选择

## 四、藏宝阁（Cbg）

### 已实现

| 功能 | 说明 |
|------|------|
| 上架出售 | 选择账号 → 物品名称 → 上架价格，生成在售记录 |
| 记录购买 | 选择账号 → 物品名称 → 购买价格 → 备注 |
| 成交确认 | 点击"已售"→ 输入成交价 → 自动计算手续费（费率可配）→ 自动计算到账日（天数可配） |
| 手动下架 | 在售物品可手动下架 |
| 在售看板 | 卡片列表，>7 天黄色预警，>14 天红色预警 |
| 统计卡片 | 在售数量 / 本月成交 / 手续费 / 到手合计 / 平均在售天数 |

### 待优化

- 下架原因目前固定"手动下架"，不支持自定义原因
- 成交后无"修改成交信息"功能（只能编辑生成的记录）

## 五、会话历史（Sessions）

### 已实现

| 功能 | 说明 |
|------|------|
| 自动记录 | 每次下线自动归档会话：账号名、开始时间、结束时间、在线时长 |
| 统计卡片 | 会话总数 / 累计在线 / 今日在线 / 账号数 |
| 按天分组 | 会话列表按日期分组，显示每天会话次数 |
| 账号筛选 | 下拉按账号过滤 |
| 时长格式化 | 自动显示为"XhXXm"格式 |

### 待优化

- 不支持删除单条会话记录
- 不支持导出会话数据
- 无日历/热力图可视化
- 不支持手动创建会话记录（如补录之前的上线）

## 六、设置（Settings）

### 已实现

| 功能 | 说明 |
|------|------|
| 账号管理 | 新增账号（名称/服务器/备注），删除账号 |
| 物品字典 | 新增物品（名称/分类/参考单价），删除物品；分类包含：道具/装备/消耗品/梦幻币/宠装/其他 |
| 藏宝阁费率 | 手续费率（%）、到账天数，修改后实时生效 |
| 月度预算 | RMB 月度预算，超限时看板顶栏提醒 |
| 主题切换 | 6 种预设主题（mint/lavender/sunset/ocean/forest/midnight）+ 自定义颜色 |
| 导入导出 | JSON 全量导入导出（合并/覆盖两种模式）；CSV 导出 |
| 桌面端 | Tauri 环境支持原生文件对话框打开 JSON 文件导入 |

### 待优化

- 导入无预览，无法在导入前看到将要合并的数据
- 导入无冲突检测（如同一 ID 的记录覆盖还是跳过）
- 删除账号不会级联删除关联记录（记录保留但 accountName 不变）
- CSV 导出未按大类分 sheet/分文件，目前统一一个 CSV

## 八、已知问题 & 优先修复建议

### 高优先

| 问题 | 说明 | 建议 |
|------|------|------|
| Cargo.toml 版本不同步 | Release 文件名还是旧版本号（如 v0.1.4 的文件名还是 `ZDream_0.1.2_*.exe`） | 发版前同步更新 `src-tauri/tauri.conf.json` 和 `src-tauri/Cargo.toml` 的 version |
| macOS Gatekeeper 拦截 | 未签名 App 打开报"已损坏" | 已在文档说明 xattr -cr 绕过，长期方案需 Apple Developer ($99/年) |

### 中优先

| 问题 | 说明 | 建议 |
|------|------|------|
| 快捷模板无管理 | 只能使用预设模板，不能新增/编辑/删除 | 在设置页或记账页加模板管理入口 |
| 删除账号不级联 | 删账号后历史记录仍保留，accountName 变成悬挂引用 | 删除时提示"该账号有 N 条记录，是否一并删除？" |
| 导入无预览 | 导入 JSON 前看不到内容，可能误覆盖 | 加一个导入预览弹窗 |
| CSV 导出单一 | 所有记录混在一个 CSV，无分类 | 按游戏收支/点卡消费/藏宝阁交易分 sheet 或分文件 |
| 流水筛选弱 | 只有账号/大类/关键词，没有日期范围 | 加开始日期～结束日期筛选 |

### 低优先

| 问题 | 说明 | 建议 |
|------|------|------|
| 响应式未适配 | 目前为桌面窗口设计，小屏幕布局可能错乱 | 桌面应用优先级低，可暂缓 |
| 空状态缺失 | 多个页面无数据时只有简单的"暂无"文字 | 加引导性空状态（图示 + 操作按钮） |
| 错误处理弱 | JSON 导入失败时 toast 提示较简单 | 加详细错误信息（哪一行/哪个字段有问题） |
| Toast 无队列 | 多个 toast 同时触发会互相覆盖 | 加一个简单的 toast 队列 |

## 十、快捷操作速查

| 操作 | 方式 |
|------|------|
| 上线账号 | 点击顶栏账号芯片 |
| 全部下线 | 点击"全部下线"按钮 |
| 快捷记账 | `Ctrl+Shift+R` |
| 游戏收支 | 记账页 → 游戏收支 tab → 填表 → 记录 |
| 购买点卡 | 记账页 → 点卡 tab → 填表 → 记录 |
| RMB 消费 | 记账页 → 消费 tab → 填表 → 记录 |
| 藏宝阁上架 | 藏宝阁页 → 上架出售 |
| 藏宝阁购买 | 藏宝阁页 → 记录购买 |
| 确认售出 | 藏宝阁页 → 在售物品 → 已售 |
| 编辑记录 | 记账页 → 任一历史面板 → 编辑 |
| 删除记录 | 记账页 → 任一历史面板 → 删 |
| 切换主题 | 设置页 → 外观 → 点击主题 |
| 导出数据 | 设置页 → 数据 → 导出 JSON / CSV |
| 导入数据 | 设置页 → 数据 → 导入 JSON |
| 发版 | `git tag v0.x.x && git push origin v0.x.x` |
