## 1. 核心功能概览

* **极速打字记账**：打字搜索物品/玩法，纯键盘极速完成多账号收支记录。
* **桌面独立悬浮球/悬浮窗**：360px×520px 精致悬浮面板，游戏窗口前置常驻。
* **师门任务助手**：多角色师门计时器与店铺代码（野宠、三药、家具）速查。
* **OCR 选区截图**：一键选区识别游戏屏幕内交易文字与消息。
* **账号与财务看板**：多角色收益归集、藏宝阁提现、扣费与月度预算提醒。

## 3. 桌面悬浮窗与极速记账

### 3.1 唤出与搜索
1. 按下 **<kbd>Ctrl</kbd> + <kbd>`</kbd>** 唤出悬浮窗，光标全自动聚焦于主搜索框；
2. 输入物品名称（如 `金柳露` / `元宵`）或玩法名称（如 `师门`）；
3. 按 **<kbd>↓</kbd>** / **<kbd>↑</kbd>** 方向键在匹配列表中上下选择，按下 **<kbd>Enter ↵</kbd>**。

### 3.2 极速参数确认（全程无需鼠标）
进入记账确认卡片后：
* **切换类型**：按键盘 **<kbd>←</kbd>** 或 **<kbd>→</kbd>** 键，在 **`[+ 收入]` ➔ `[⚡ 消耗]` ➔ `[💰 卖出]`** 之间循环切换；
* **切换账号**：按键盘 **<kbd>Tab</kbd>** 键，在在线角色账号之间切换；
* **修改单价**：光标默认聚焦在【单价】框，直接键盘打字输入金额（*已禁用 ↑/↓ 键误触改价*）；
* **修改数量**：按下 **<kbd>Tab</kbd>** 或点击【数量】框，可用键盘 **<kbd>↑</kbd>** / **<kbd>↓</kbd>** 微调数量；
* **确认提交**：按 **<kbd>Enter ↵</kbd>** 确认提交记账，光标自动闪电重置归位至搜索框；
* **取消返回**：按 **<kbd>Esc</kbd>** 取消当前记账返回搜索框，再按 **<kbd>Esc</kbd>** 将悬浮窗缩为小球。

### 3.3 📌 悬浮窗固定与自由拖拽
* **固定展开**：点击悬浮窗右上角的 **`📌`** 按钮，面板将锁定展开状态；
* **防失焦收起**：在固定模式下，鼠标点击其他游戏界面或窗口失去焦点时**不会自动收起**；
* **最上层置顶**：悬浮窗始终保持置顶在所有游戏窗口和系统应用最上方，避免被遮挡；
* **自由拖拽**：在固定模式下仍可按住标题栏空白区域，随心所欲拖拽移动至屏幕任意位置。

## 4. 师门任务助手模式

### 4.1 开启师门模式
* **搜索开启**：在悬浮窗搜索框输入 `师门` 或 `sm`，选择 `🧙 开启 师门任务助手` 按回车；
* **侧边栏开启**：主界面在活动列表中选择“师门任务”。

### 4.2 核心功能
* **多账号师门计时**：点击角色卡片开启师门任务计时，自动统计完成用时与收益；
* **店铺代码速查**：切换至“店铺速查”Tab，点击低价野生召唤兽、三药、家具编码即可一键复制；
* **醒目退出按钮**：顶栏设有点阵高亮的 `[ ✕ 退出模式 ]` 胶囊按钮，点击可随时切回默认极速记账；
* **<kbd>Esc</kbd> 键收起**：在师门模式下按下 **<kbd>Esc</kbd>** 键**不会退出师门模式**，而是直接缩为悬浮球，便于做任务时常驻。

## 5. AI 大模型与智能截图记账

1. **配置 AI 大模型**：在【设置】➔【高级配置】中选择预设（支持 DeepSeek、OpenAI、Kimi、本地 Ollama 或自定义 API），填写 API Key 与 Base URL 并测试连通性；
2. **快捷键框选**：在任何游戏画面按快捷键 **<kbd>Ctrl</kbd> + <kbd>A</kbd>** 划选要识别的交易/聊天/奖励消息区域；
3. **弹出智能分析窗口**：松开鼠标后将弹出【📷 智能截图分析】可交互窗口：
   * **状态展示**：经历 `🔍 OCR 识字` ➔ `🧠 AI 思考意图` ➔ `✍️ 人工确认`；
   * **上半部分**：直观预览所截取的游戏图片与 OCR 识别原始行文本；
   * **下半部分**：展示 AI 分析得出的交易意图（如：*摆摊卖出5个金柳露，获得60万梦幻币*），以及预填好的账号、物品名称、单价、数量与收支类型；
4. **人工安全确认**：用户可手动修改任意表单字段，确认无误后点击 **`[ ✅ 确认并写入账本 ]`** 正式记账！

## 6. 账号管理与在线状态

* 在主界面【账号管理】中添加游戏角色（如 `主号`、`副号甲`）；
* 悬浮窗顶栏会展示当前在线账号列表（如 `3/4 在线`），点击账号芯片可快捷切换记账角色。

---

## 7. 快捷键自定义与录入

1. 打开主界面侧边栏【设置】 ➔ 【数据与快捷键】；
2. 点击 **“全局唤出悬浮窗快捷键”** 或 **“全局截图识别快捷键”** 的录入框；
3. 输入框呈现 `● 请按下快捷键...` 状态时，直接按下想要的键盘组合键（如 <kbd>Ctrl</kbd>+<kbd>`</kbd> / <kbd>Alt</kbd>+<kbd>S</kbd>）；
4. 系统自动录入并实时检测冲突。如与其他功能冲突，下方将呈现红色警告提示。

---

## 8. 数据安全与备份

* **纯本地存储**：所有记账数据存储于本地 SQLite 数据库或本地 localStorage，不上传任何云端服务器。
* **数据导出**：支持在设置中一键导出 JSON / CSV 格式数据备份。
